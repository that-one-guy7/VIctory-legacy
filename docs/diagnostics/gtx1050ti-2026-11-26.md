# GTX 1050 Ti run — 2026-11-26

This is a compact, text-only summary of the machine log shared for this run. The raw
`ztrx.log` is intentionally not tracked: it is machine-specific, larger than the
repository's 512 KiB text-file limit, and is ignored by `.gitignore`.

## Environment

- Windows 10 build 19044, Intel Core i7-6700 (8 logical processors), 16 GiB RAM.
- NVIDIA GeForce GTX 1050 Ti, 4 GiB reported adapter memory; driver 32.0.15.8278.
- The launcher used the **release** profile, not the diagnostics profile.
- DXGI local-memory budget varied around 3,345–3,403 MiB.

## Confirmed rendering problems

- The title requested a 1,245,184-entry view heap. The NVIDIA host heap probe failed
  above 1,000,000 entries, so indices beyond the host's retained range are mapped
  to a null descriptor. The log did not report dynamic descriptor-slot exhaustion.
- Shader translation refused compute shader `a929109552ce1e84` because
  `v_permlanex16_b32` was unsupported.
- Shader translation refused compute shader `f133e35efed2a48a` because a lane-mask
  exchange occurred where not every lane runs.
- Shader translation refused compute shader `ceb5eb68cd99cb07` because descriptor
  address/format bits were read as data.
- Pixel shaders `7d0f14ce44746d7e` and `6b6db9f1a526daeb` also read descriptor
  data in a form the older translator refused.
- Pipeline backlogs stayed large: sampled frame diagnostics showed roughly
  1,400–2,200 pipelines still being made. Later frame summaries reported hundreds
  to thousands of dropped draws/dispatches waiting for host pipelines.

## Device-removal evidence

- Optional local UAV allocations were repeatedly refused near the 70% local-budget
  setting, and mesh scratch fell back to CPU-visible shared memory.
- Despite those guards, local usage later reached about 4,029 MiB against a
  3,403 MiB budget.
- The device was removed after a submission of 22 command lists. The log reported
  `0x887A0005` and `0x887A0004`, but no DRED breadcrumbs or page-fault details.
- Because this was a release run without DRED, the exact offending command/resource
  cannot be identified from this log alone. Device removal is confirmed; a single
  root cause is not.

## Follow-up

The renderer changes in the related PR address the confirmed permlane and
descriptor-size translator gaps, apply the existing local-memory gate to new
reconstructible title-filled texture copies, and raise the default pipeline
worker count from four to five on an eight-logical-processor machine. The
divergent lane-mask exchange remains unsupported pending a safe cross-wave
implementation. The next hardware run should use a diagnostics build with
`VICTORY_D3D12_DRED=1` so command breadcrumbs and page-fault data are captured.
